# Current Context

## Purpose
To provide the immediate context of what the AI agents are currently working on, ensuring seamless continuity between sessions and agents without needing to re-read the entire project history.

## Update Rules
- Overwrite or update this file whenever an agent switches context, starts a new primary task, or completes a sub-task.
- Keep the information concise and relevant to the immediate next steps.
- Clear out stale context that is no longer applicable.

## Template Structure
- **Active Task:** [What is currently being worked on]
- **Current Phase:** [E.g., Implementation, Testing, Debugging]
- **Recent Discoveries/Context:** [Important context gathered recently]
- **Blockers/Challenges:** [Any current hurdles]
- **Immediate Next Steps:** [What the AI needs to do next]
