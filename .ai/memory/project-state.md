# Project State

## Purpose
To give a high-level overview of the project's overall health, current phase, and major milestones achieved, providing agents with a macro-level understanding of the repository.

## Update Rules
- Update only at major milestones (e.g., initial setup complete, alpha release, major refactor).
- Keep this document stable and high-level; granular details belong in other memory files.

## Template Structure
- **Current Phase:** [E.g., Initial Setup, MVP Development, Production Maintenance]
- **Overall Health:** [Green, Yellow, Red with brief explanation]
- **Major Milestones Achieved:**
  - [Date] - [Milestone Description]
- **Core Dependencies Status:** [Any significant updates or migrations pending for core tech]
