# Current Sprint

## Purpose
To track the active goals, features, and tasks for the current development iteration, providing AI agents with an overview of immediate priorities.

## Update Rules
- Update at the beginning of a new sprint with the overall goal and task list.
- Modify the status of individual tasks (e.g., Todo -> In Progress -> Done) as work progresses.
- Move completed tasks out of this file at the end of the sprint.

## Template Structure
- **Sprint Goal:** [High-level objective for this iteration]
- **Timeframe:** [Start Date] - [End Date]
- **Active Tasks:**
  - [ ] [Task 1]
  - [/] [Task 2] (In Progress)
  - [x] [Task 3] (Done)
- **Sprint Notes:** [Any relevant notes or scope changes]
