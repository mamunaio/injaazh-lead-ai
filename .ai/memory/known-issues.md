# Known Issues

## Purpose
To track bugs, technical debt, and pending issues that are identified but not currently being worked on, ensuring they are not forgotten.

## Update Rules
- Add an entry when a new bug is found but deferred.
- Mark as `[Resolved]` or remove the entry when the issue is fixed.
- Review periodically during planning phases.

## Template Structure
- **Issue:** [Description of the problem or tech debt]
- **Severity:** [Low, Medium, High, Critical]
- **Impact:** [How this affects the system or users]
- **Workaround:** [Any known temporary fixes]
- **Status:** [Open, In Progress, Resolved]
