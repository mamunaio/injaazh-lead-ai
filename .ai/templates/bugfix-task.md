## 7. Self Review Checklist
- [ ] Bug is fully resolved locally.
- [ ] Regression test passes successfully.
- [ ] Unrelated code remains untouched.
- [ ] Issue tracker is updated.

## 8. Output Format
[Format for detailing the fix, root cause, and tests added]

- Regression tests are integrated into the CI pipeline.
